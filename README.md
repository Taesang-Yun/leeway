# Leeway · 안 늦는 길찾기

A conservative transit planner for Korea. It tells you when to leave so you won't be late,
accounting for headways, transfers, delays, and first/last service.

- App: https://taesang-yun.github.io/leeway/
- Data: [ODsay LAB](https://lab.odsay.com) (free Basic plan, 30 calls/day; responses are cached in the browser)
- The ODsay key in `index.html` only works from `taesang-yun.github.io`.
